# 竖屏演示视频脚本

建议成片：60–90 秒，1080 × 1920，屏幕录制配旁白和大字幕。所有画面使用 `examples/` 中的虚构数据。

| 时间 | 画面 | 旁白 | 屏幕字幕 |
|---|---|---|---|
| 0–5 秒 | 快速扫过杂乱评论区 | 小红书问题帖里，真正有用的答案往往藏在评论区。 | 高赞不等于有效答案 |
| 5–14 秒 | 标出建议、亲历、猜测混在一起 | 但直接建议、亲历经验、风险提醒和随口猜测，经常混在一起。 | 答案 / 经验 / 风险 / 猜测 |
| 14–24 秒 | 打开 Codex，输入调用提示 | 我做了一个同时支持 Codex 和 Claude Code 的 Skill。 | xhs-question-solutions |
| 24–42 秒 | 展示问题帖判定和评论分类 | 它先找出真正提问题的帖子，再把评论按证据性质分开。 | 识别问题帖 → 分类评论 |
| 42–60 秒 | 展示带 c1、c3、c4 的方案步骤 | 每个执行步骤都必须能回到具体评论；没有证据的内容只能进入待验证。 | 每一步都有评论 ID |
| 60–72 秒 | 展示冲突观点和风险区 | 遇到冲突，不取平均，而是保留双方观点、条件和风险。 | 不隐藏冲突，不伪造共识 |
| 72–84 秒 | 打开 GitHub 项目首页和安装命令 | 项目已经开源，克隆后即可使用，也可以一键安装到个人 Skills。 | GitHub：xhs-question-solutions |
| 84–90 秒 | 定格项目名 | 如果你也想把评论区经验变成可追溯方案，可以试试它。 | 查看 GitHub 获取项目 |

## 录制清单

- 使用 `examples/sample-input.json`，不要展示真实 Cookies 或用户数据。
- 录制 Codex 的 `$xhs-question-solutions` 调用和 Claude Code 的 `/xhs-question-solutions` 调用之一。
- 展示 [examples/sample-output.md](../examples/sample-output.md) 中的方案、冲突和证据 ID。
- GitHub 地址确认后，再替换结尾占位字幕。
- 导出前检查画面中没有账户名、本地绝对路径、通知和浏览器隐私信息。
