# 判断量表

## 问题帖

作者的主要意图必须是获得具体答案、建议、诊断、选择帮助或他人亲历反馈。问号只是弱信号；反问、互动钩子、商品引流和标题党不因此成为问题帖。明确问题和约束时 `confidence` 为 0.8-1.0；意图可推断但不完整为 0.5-0.79；主要靠猜测则低于 0.5，并排除在默认结果外。

## 评论类别

- `direct_answer`：直接回答并给出明确判断或方法。
- `firsthand_experience`：明确描述自己或近亲的过程或结果。
- `risk_warning`：指出副作用、失败条件、成本或安全风险。
- `counterexample`：提供与主流结论相反的具体案例。
- `clarifying_question`：补问条件，不提供答案。
- `speculation`：推测、传闻或缺乏可核对细节的断言。
- `off_topic`：闲聊、求链接、广告或无关内容。

每条评论只选择一个最能代表其证据性质的主类别；兼具作用写入 `claim`，不要输出多个 `category`。亲历经验不等于普遍有效。检查是否有具体动作、适用前提、时间或成本、可观察结果、失败条件；缺少两项以上时降低置信度。多条独立评论同意只能写成“评论区共识”。相关回复不算独立证据。冲突观点分别保留条件和证据 ID。方案步骤只能由直接答案、亲历经验或风险提醒支持；猜测只进入待验证区。
