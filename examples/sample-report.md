# 小红书问题帖解决方案

## 如何处理一楼衣柜后反复出现的墙面霉菌并减少复发？

### 一句话答案
先做好防护并排查持续潮湿或渗水原因，处理根因后再除霉和观察复发。

### 可执行步骤
1. **处理前先通风并核对产品安全说明，不把大面积喷酒精作为默认方案。**（证据：c2, c3）
   - 适用：计划使用酒精或其他挥发性产品；现场能够安全通风
   - 验证：已确认产品适用表面、通风要求和火源隔离条件。
   - 停止：存在火源、通风不足或敏感人群；产品说明与现场条件不匹配
2. **检查墙体潮湿、外墙渗水等持续水分来源；确认原因后联系责任方处理。**（证据：c1, c4）
   - 适用：霉斑反复出现或墙面持续潮湿
   - 验证：找到可观察的潮湿来源，或由物业、房东、专业人员完成检查。
   - 停止：原因无法安全确认；涉及结构、外墙或管线问题
3. **根因处理后再除霉，记录位置和日期并观察是否复发。**（证据：c1, c4）
   - 适用：持续水分来源已经处理或排除
   - 验证：处理区域在观察期内保持干燥且没有新增霉斑。
   - 停止：一周内快速复发；霉斑扩大或出现明显健康不适
